# e-sign web application

The React Router interface and Hono HTTP server live here. This package shares the root workspace dependencies and should be run through the root scripts.

- [Local setup and run steps](../../README.md#quick-start)
- [Container setup](../../docker/README.md)
- [Architecture](../../ARCHITECTURE.md)
- [Verified behavior and limitations](../../docs/FEATURES.md)

From the project root, use `npm run dev` for development or `npm run build -w @e-sign/remix` and `npm start` for the production build.
