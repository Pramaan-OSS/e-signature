# Design application

The interface uses shared ground/glass surfaces, typography, spacing and focus tokens.

The template keeps its document-signing routes and uses shared ground/glass, typography, spacing, radius, focus and control tokens through shared UI components. Fonts are served locally: Fraunces, Geist and JetBrains Mono. Signing PDFs retain their own document ink and signature fonts; these are document content rather than the app theme.

Signing confirmations use inline cards. The actions page uses saved requests and neutral action buttons, with a single decision control when one is available. Responsive checks target 1142×732 and a 400px floor.
